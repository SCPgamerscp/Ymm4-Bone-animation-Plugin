## 準備: パーツ画像を用意する

このプラグインは「切り抜き（Cutout）方式」です。
キャラクターを**パーツごとに分割したPNG画像**を用意してください。

```
character/
├─ body.png        体
├─ head.png        頭
├─ hair_back.png   後ろ髪
├─ hair_front.png  前髪
├─ arm_l_upper.png 左上腕
├─ arm_l_lower.png 左前腕
├─ eye_open.png    目（開）
├─ eye_half.png    目（半目）
├─ eye_close.png   目（閉）
├─ mouth_close.png 口（閉）
├─ mouth_half.png  口（半開き）
└─ mouth_open.png  口（開）
```

### 画像を作るときのコツ

- **透過PNG**にしてください
- **関節部分は少し重ねて**描いておくと、曲げたときに隙間が空きません
- 差分画像（目・口）は**すべて同じキャンバスサイズ**にすると位置がずれません
- パーツごとに切り出すとき、余白をトリミングしすぎないほうが位置合わせが楽です

## チュートリアル1: 首を振らせる（FKの基本）

### 手順

**1. 図形アイテムを追加する**

タイムラインに図形アイテムを追加し、図形の種類で
**「2Dボーンアニメーション」** を選びます。

**2. 初期ボーンを確認する**

「ボーン階層」に「体 → 頭」の2ボーンが最初から用意されています。

```
体
└─ 頭
```

**3. 体に画像を割り当てる**

ツリーで「体」を選択します。下部に設定が出るので、
「差分画像」欄の `+` を押してスロットを追加し、
`ファイル` から `body.png` を選びます。

**4. アンカーポイントを合わせる**

「体」の `アンカーX` / `アンカーY` を調整します。
これは**画像内での回転中心**で、`0.5, 0.5` が画像の中心です。

体の場合は腰のあたりを中心にしたいので、`0.5, 0.9` くらいにします。

```
        ┌─────────┐  ← Y = 0.0
        │         │
        │  body   │
        │         │
        │    ●    │  ← Y = 0.9 （ここが回転中心）
        └─────────┘  ← Y = 1.0
        ↑    ↑    ↑
       0.0  0.5  1.0
```

**5. ボーンの長さを設定する**

「体」の `長さ` を、**腰から首までの距離**（px）にします。
子ボーンである「頭」はこの先端に接続されるためです。

たとえば体の画像が高さ300pxで、腰から首まで250pxなら `250` と入れます。

**6. 頭に画像を割り当てる**

ツリーで「頭」を選択し、同じように `head.png` を割り当てます。
アンカーは首のあたり（`0.5, 0.9` 程度）にします。

**7. プレビューで確認する**

「ボーンを表示」がオンなら、プレビューに青い線でボーンが表示されます。
体の先端に頭が繋がっていればOKです。

ずれている場合は「体」の `長さ` か、頭の `X` / `Y` で微調整します。

**8. アニメーションさせる**

「頭」の `回転` にキーフレームを打ちます。

| フレーム | 回転 |
| --- | --- |
| 0 | -90（初期値のまま） |
| 30 | -75 |
| 60 | -90 |

再生すると首を傾げる動きになります。

> **なぜ初期値が -90 なのか**
> このプラグインでは**角度0度が+X方向（右）**です。
> 頭は体の上（-Y方向）に伸びるので、初期値が -90 度になっています。

**体を回すと頭も一緒についてくる**ことを確認してください。これがFK（順運動学）です。

## チュートリアル2: 腕をIKで動かす

「手先を指定した位置へ持っていくと、肘が自動で曲がる」動きを作ります。

### 手順

**1. 腕のボーンを追加する**

ツリーで「体」を選択し、`＋ 子を追加` を押します。
名前を「上腕」に変え、`長さ` を上腕の長さ（例: 100）にします。

続いて「上腕」を選択したまま `＋ 子を追加` を押し、
「前腕」を作ります。`長さ` は前腕の長さ（例: 90）です。

```
体
├─ 頭
└─ 上腕
   └─ 前腕
```

**2. 画像を割り当てる**

「上腕」に `arm_l_upper.png`、「前腕」に `arm_l_lower.png` を割り当てます。
アンカーはそれぞれ**肩**と**肘**の位置に合わせます。

**3. 前腕でIKを有効にする**

ツリーで**「前腕」**（＝チェーンの末端）を選択し、
`IKを有効化` をオンにします。

| 設定 | 値 |
| --- | --- |
| IKを有効化 | ON |
| IKチェーン長 | **2** |
| IK影響度 | 1 |

チェーン長2は「前腕 + 上腕」の2本を曲げるという意味です。
2の場合は解析解（余弦定理）で厳密に解かれます。

**4. ターゲットを動かす**

プレビューに**赤い円**が現れます。これがIKターゲットです。
ドラッグすると、手先がそこへ向かうように肘が自動で曲がります。

キーフレームで動かしたい場合は、前腕の
`IKターゲットX` / `IKターゲットY` にキーフレームを打ちます。

| フレーム | IKターゲットX | IKターゲットY |
| --- | --- | --- |
| 0 | 100 | 50 |
| 30 | 180 | -80 |
| 60 | 100 | 50 |

**5. 肘の向きを直す**

肘が逆向き（あり得ない方向）に曲がる場合は、
`曲がる向きを反転` をオンにします。

**6. FKとIKを混ぜる**

`IK影響度` は `0`（完全にFK）〜`1`（完全にIK）のブレンド率です。
これ自体もキーフレーム対応なので、
「途中からIK制御に切り替える」といった演出ができます。

| フレーム | IK影響度 | 挙動 |
| --- | --- | --- |
| 0 | 0 | FKで手描きした回転がそのまま使われる |
| 20 | 1 | IKターゲットへ完全に追従 |

### 補足: チェーン長3以上

尻尾や触手のように長いチェーンは `IKチェーン長` を3以上にします。
この場合はCCD法（反復解法）が使われます。
`IK反復回数` を増やすと精度が上がりますが、少し重くなります。

## チュートリアル3: 髪を揺らす（物理演算）

キャラが動いたときに髪が自動で追従して揺れるようにします。

### 手順

**1. 髪のボーンを作る**

ツリーで「頭」を選択し、`＋ 子を追加` で「後ろ髪」を作ります。

```
体
└─ 頭
   └─ 後ろ髪
```

**2. 下向きに配置する**

髪は頭から**下に垂れる**ので、`回転` を `90` にします。
（0度が右向きなので、90度で下向きになります）

`長さ` は髪の長さ（例: 150）にします。

**3. 画像を割り当てる**

`hair_back.png` を割り当て、アンカーを**髪の付け根**に合わせます。

**4. 物理演算を有効にする**

「後ろ髪」を選択したまま `物理演算を有効化` をオンにします。

| 設定 | 既定値 | 調整の目安 |
| --- | --- | --- |
| 硬さ | 12 | 大きい = 元の位置へすぐ戻る。ショートヘアなら20前後 |
| 減衰 | 3.5 | 大きい = 揺れがすぐ止まる。小さいとふわふわ揺れ続ける |
| 慣性 | 1 | 大きい = 親の動きによく反応する |
| 重力 | 0 | 下向きに垂れる力。ロングヘアなら5〜15 |
| 角度制限 | 45 | これ以上は曲がらない。大きすぎると不自然に折れます |

**5. 親を動かして確認する**

「頭」の `X` にキーフレームを打って左右に振ってみてください。

| フレーム | 頭のX |
| --- | --- |
| 0 | 0 |
| 15 | 60 |
| 30 | -60 |
| 45 | 0 |

再生すると、頭の動きに遅れて髪が揺れます。

### 揺れない場合のチェックポイント

**揺れの力は「ボーンの軸に対して垂直な成分」だけです。**

髪が下向き（90度）のとき、頭を**左右**に振れば揺れますが、
**上下**に動かしても揺れません。髪が伸びている方向へ引っ張っても
横には揺れない、という物理的に正しい挙動です。

```
    下向きの髪の場合

    ← 左右に動かす → 揺れる ○
    ↑ 上下に動かす → 揺れない ×
```

他にも以下を確認してください。

- 全体設定の `物理演算を有効化` がオンになっているか
- 親ボーンが実際に動いているか（親が静止していると揺れる理由がありません）
- `慣性` が0になっていないか

### 揺れが暴れる場合

- `減衰` を上げる
- `角度制限` を下げる
- `慣性` を下げる

### 多段の髪

より柔らかい動きにしたい場合は、髪を複数のボーンに分割して繋げます。

```
頭
└─ 後ろ髪1  （硬さ 15）
   └─ 後ろ髪2  （硬さ 10）
      └─ 後ろ髪3  （硬さ 6）
```

**先端に向かうほど硬さを下げる**と、毛先がしなやかに動きます。

## チュートリアル4: 口パクと目パチ

### 口パク

**1. 口のボーンを作る**

「頭」の子として「口」を作ります。

**2. 差分画像を3つ登録する**

「差分画像」欄で `+` を3回押し、それぞれ名前とファイルを設定します。

| 名前 | ファイル |
| --- | --- |
| 閉じ | mouth_close.png |
| 半開き | mouth_half.png |
| 開き | mouth_open.png |

> **重要**: ここで付けた「名前」を、次のステップで指定します。
> ファイル名ではなくスロット名で参照するので、名前を分かりやすく付けてください。

**3. 口パクを有効にする**

| 設定 | 値 |
| --- | --- |
| 口パク連動を有効化 | ON |
| 口パクスロット名 | `閉じ, 半開き, 開き` |
| 口パク拡大率 | 0（お好みで） |

スロット名は**カンマ区切り**で、**閉じている状態から順に**並べます。
`、`（読点）や改行でも区切れます。

音声の大きさに応じて、左から右のスロットへ切り替わります。

`口パク拡大率` を上げると、口の開き具合に応じてボーンが少し拡大し、
より大げさな口パクになります。

### 目パチ

**1. 目のボーンを作る**

「頭」の子として「目」を作ります。

**2. 差分画像を3つ登録する**

| 名前 | ファイル |
| --- | --- |
| 開き | eye_open.png |
| 半目 | eye_half.png |
| 閉じ | eye_close.png |

**3. 目パチを有効にする**

| 設定 | 値 | 説明 |
| --- | --- | --- |
| 目パチを有効化 | ON | |
| 目パチスロット名 | `開き, 半目, 閉じ` | 開いた状態から順に |
| まばたき間隔 | 4 | 4秒ごとにまばたき |
| まばたき時間 | 0.16 | 1回のまばたきの長さ（秒） |

**4. 複数キャラのタイミングをずらす**

全体設定の `目パチシード` を変えると、まばたきのタイミングがずれます。
キャラごとに違う値（例: 1234, 5678, 9012）にすると、
画面内の全員が同時にまばたきする不自然さを避けられます。

> **補足**: まばたきは**同じ時刻なら必ず同じタイミング**になります。
> シークしても結果が変わらないため、プレビューと最終出力が一致します。

### 手動で差分を切り替える

口パク・目パチのどちらも**無効**なボーンでは、
`差分番号` の値がそのまま使われます。

たとえば「手」のボーンで
「グー = 0 / チョキ = 1 / パー = 2」の差分を登録しておき、
`差分番号` にキーフレームを打てば手の形を切り替えられます。

| フレーム | 差分番号 | 表示 |
| --- | --- | --- |
| 0 | 0 | グー |
| 20 | 1 | チョキ |
| 40 | 2 | パー |

> 優先順位は **手動指定 → 口パク → 目パチ** です。
> 口パクや目パチを有効にしているボーンでは `差分番号` は無視されます。

## チュートリアル5: 腕を体の後ろへ回す（動的Z順）

`Z順` は**アニメーション可能**な値です。これを使うと
「腕を背中に回す」といった前後関係の入れ替えができます。

### 手順

**1. 各ボーンの基準Z順を決める**

| ボーン | 基準Z順 | 位置 |
| --- | --- | --- |
| 後ろ髪 | -20 | 一番奥 |
| 体 | 0 | |
| 頭 | 10 | |
| 前髪 | 20 | |
| 腕 | 5 | 体より手前 |

**Z順が大きいほど手前**に描画されます。

**2. 腕のZ順にキーフレームを打つ**

| フレーム | 腕のZ順 | 見え方 |
| --- | --- | --- |
| 0 | 5 | 体より手前（普通に腕が見える） |
| 30 | 5 | |
| 31 | -10 | 体より奥（背中に回った） |

**3. 切り替えのタイミング**

Z順もキーフレーム補間されるため、値が滑らかに変化します。
**腕が体に隠れる瞬間**に切り替わるようキーフレームを配置すると、
入れ替わりが目立ちません。

腕の回転アニメーションと合わせて、
「腕が体の横を通過する瞬間」にZ順のキーフレームを置くのがコツです。

> 同じZ順のボーンは、ツリー（ボーンリスト）の**上から順**に描画されます。
> `▲` / `▼` ボタンで並べ替えられます。

## チュートリアル6: テンプレートで使い回す

作ったボーン構造を保存して、別のアイテムやプロジェクトで再利用できます。

### 保存

1. 「テンプレート」欄の `保存` を押す
2. 保存先とファイル名を決める（例: `mychar.json`）

ボーンの階層・長さ・アンカー・物理設定・IK設定・
画像ファイルパスがすべてJSONで保存されます。

### 読み込み

1. 新しい図形アイテムで「2Dボーンアニメーション」を選ぶ
2. 「テンプレート」欄の `読み込み` を押す
3. 保存したJSONを選ぶ
4. 確認ダイアログで `OK` を押す

> **注意**: 読み込むと**現在のボーンはすべて置き換えられます**。
> 打ったキーフレームも失われるので、確認ダイアログをよく読んでください。

### 使いどころ

- 同じキャラを複数のシーンで使う
- 「人型の標準ボーン構成」を作っておいて、画像だけ差し替える
- ボーン構成をチームで共有する

JSONのフォーマット詳細は [template-format.md](template-format.md) を参照してください。

## よくあるトラブル

### 画像が表示されない

| 原因 | 対処 |
| --- | --- |
| 差分画像が登録されていない | 「差分画像」欄で `+` してファイルを指定 |
| ファイルパスが間違っている | ファイルを選び直す。移動・リネームしていないか確認 |
| 不透明度が0になっている | そのボーンと**すべての親**の `不透明度` を確認（親の値が乗算されます） |
| 画面外にある | `X` / `Y` をリセットしてみる |

> ボーンのガイド線だけ表示される場合は、ボーン構造は正しく、
> 画像の割り当てだけが問題です。

### パーツの位置がずれる

- **アンカーポイント**が関節の位置に合っているか確認
- **親ボーンの `長さ`** が実際の関節間距離と合っているか確認
  （子は親の**先端**に接続されます）
- 微調整は子ボーンの `X` / `Y` で行えます

### 回転すると変な位置に飛ぶ

アンカーポイントが回転中心なので、これが関節からずれていると
回転時に大きく動きます。アンカーを関節の位置へ合わせてください。

### 髪が揺れない

[チュートリアル3の「揺れない場合のチェックポイント」](#揺れない場合のチェックポイント)を参照。
特に「ボーンの軸方向に動かしても揺れない」仕様に注意してください。

### 髪が吹き飛ぶ・暴れる

- タイムラインをシークした直後は、内部状態がリセットされて落ち着きます
- `減衰` を上げ、`角度制限` を下げてください
- `慣性` が大きすぎないか確認してください

### 肘・膝が逆に曲がる

IKを有効にしたボーンの `曲がる向きを反転` をオンにします。

### IKで腕が届かない

ターゲットがボーンの合計長より遠い場合、腕はまっすぐ伸びて
最大限近づきます（これは正常な動作です）。
ボーンの `長さ` を見直すか、ターゲットを近づけてください。

### 親子関係を変更できない

ドラッグ＆ドロップで「そのボーンは自分自身の子孫にはできません」
と出る場合、循環参照になる操作です。
先に対象のボーンを `親を解除` でルートに戻してから繋ぎ直してください。

### プレビューが重い

- 「ボーンを表示」をオフにする
- 物理演算を使うボーンの数を減らす
- 画像の解像度を下げる
- IKチェーン長3以上のボーンの `IK反復回数` を下げる

### 出力にボーンのガイド線が入る

ガイド線は「ボーンを表示」がオンのときに描画されます。
最終出力前にオフにしてください。
